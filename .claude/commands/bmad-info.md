# B-Mad Method Framework Info

The B-Mad Method framework has been installed in this project.

## What is B-Mad Method?

The **B-Mad Method** (Breakthrough Method for Agile AI Driven Development) is a complete AI-driven agile development framework with specialized AI agents for software development.

## Installation Location

- **Core & Modules**: `.bmad/` directory
- **Configuration**: `.bmad/core/config.yaml` and `.bmad/bmm/config.yaml`

## Available Components

### Modules Installed
1. **BMad Core** - Foundation framework with orchestration
2. **BMad Method (BMM)** - Agile development workflows and agents

### Key Agents (YAML sources in `.bmad/bmm/agents/`)
- Product Manager (PM)
- Business Analyst
- Software Architect
- Developer (Dev)
- Scrum Master (SM)
- Test Architect (TEA)
- UX Designer
- Technical Writer

### Workflows (in `.bmad/bmm/workflows/`)
- Planning workflows (PRD, Epics, Stories)
- Implementation workflows (Dev Story, Code Review)
- Quality workflows (Testing, DoD)

## To Complete Full Installation

Run the official installer to compile agents and set up full integration:

```bash
npx bmad-method@alpha install
```
